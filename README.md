# More Cylinders, Fewer Miles

A three-scene D3 narrative visualization using a **martini-glass structure**: Scenes 1 and 2 are author-guided scenes, followed by Scene 3: a final exploratory scene.

## Files

- `index.html` — page structure
- `styles.css` — visual template and responsive layout
- `script.js` — D3 scenes, annotations, parameters, and triggers
- `cars2017.csv` — source data
- `d3.v3.min.js` — local D3 library copy
